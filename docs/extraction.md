# Extraction and ownership

This package consolidates reusable render mechanisms. It does not copy private
song assets or every historical campaign script into the distribution. Creative
scene drawing remains release-owned and can use the shared Python scene hook.

| Existing renderer family | Shared functionality now supplied by FrameRudiments |
| --- | --- |
| Gilt Trip Shorts/Canvas | Native table identity, source-time 64-pip sampling, layer placement, alpha bounds, lyric-frame ledger, endpoint fades, FFmpeg encode/probe/decode, poster/preview. |
| Blame Putin Shorts/full visualiser | Direct native catalogue sampling, saved StemLab beat grid, explicit match source/window/phase, cue-gated layers, full-duration programmes, static caption plates. |
| Clay Shorts/full film | Pinned exact source intervals and repeats, canonical LRC mapping, named native motions, no-fade option, text fit, layered transparent art, lyric tablets/signs, retained raw source provenance. |
| Paper Dreams Shorts/full film | Sprite sheets, connected-alpha component cleaning, exact-text lyric artwork, masks, alpha manipulation, extracted seeded flight model, generalized lyric-art entrance/hold/exit and per-frame scene hook for fog/custom drawing. Narrative/asset decisions stay in its adapter. |
| Silly Sausage Britain | Atlas cycles, body/sprite transforms, masks, same-pose directional trails, generated lyric artwork, bounded compositing. Specific dancers, gull routes and smoke artwork stay in its adapter. |
| Free Danny Tommo / Patriotic Revolution | Reusable beat clock, sprite/lyric composition, pinned sources, transparent layering, rendered/encoded QA evidence. Protest/crown/identity assets stay private to their releases. |
| Moderate or Good | Timed-caption concepts, separate structural cues, SRT/ASS export, full/short project modes and background composition; old estimated timings remain historical evidence. |

The local migration inventory records original paths, hashes, imports and
function names. It is private evidence outside the package. Original scripts
are preserved; they are not silently redirected, deleted or asserted to have
been regenerated. Approved existing films retain their original generators.
New adaptations can remove their duplicated clock/caption/encoder loops and
call the shared API while retaining scene drawing and provenance locally.

StemLab owns analysis, accepted-loop evidence, beat grids, matching and recorded
signals. DanceRudiments owns motion functions, schema validation and native
recording playback. FrameRudiments owns offline timeline adaptation, composition,
encoding and technical render QA. DanceMoves remains the live web runtime.
Short Shifter remains outside DanceFlow.
