# Fractal library motion demonstration: transcript and visual description

This silent two-second synthetic demonstration contains seven labelled panels:
Julia, Mandelbrot, Tricorn, Burning Ship, Celtic, Buffalo and Newton. Each panel
shows an actual FrameRudiments `procedural_field` surface using the same
dark-violet-cyan-amber-white multi-point gradient.

Across one four-beat DanceRudiments cycle, the fractal phase travels through one
normalized turn while zoom breathes and rotation sways. Fine boundary structures
shift and turn differently in each family. There is no dialogue, music or other
audio. The next frame after the video is byte-identical to the opening frame,
so playback can loop without a state jump.
